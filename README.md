# Executive Sales Dashboard Generator

A professional Python tool that creates stunning, executive-ready Excel dashboards.

## 🎯 Features

### **Professional Visualizations**
- 📈 **Sales Trend Line Chart** - Year-over-year comparison with custom markers
- 📊 **Regional Performance Bar Chart** - Top performing regions/markets
- 🥧 **Category Breakdown Pie Chart** - Product/segment distribution with percentages
- 🎯 **Customer Satisfaction Radar Chart** - Multi-dimensional performance metrics

### **Executive KPI Cards**
- 💰 Total Sales with target achievement percentage
- 📈 Total Profit with growth indicators
- 📦 Total Orders with performance metrics
- Clean, modern card design with professional styling

### **Data Processing**
- ✅ Automatic CSV encoding detection (UTF-8, Latin-1, ISO-8859-1, CP1252)
- ✅ Intelligent column mapping (works with various column names)
- ✅ Multi-year time series analysis
- ✅ Regional and categorical aggregations
- ✅ Automatic data validation and cleaning

## 📋 Requirements

### **Python Version**
- Python 3.7 or higher

### **Dependencies**
```bash
pip install pandas xlsxwriter numpy
```

Or install from requirements file:
```bash
pip install -r requirements.txt
```

---

## 🚀 Quick Start

### **1. Setup**

Clone or download the project files to your local machine:

### **2. Install Dependencies**

```bash
pip install pandas xlsxwriter numpy
```

### **3. Run the Script**

```bash
python dashboard_generator.py
```

### **4. Output**

The script will generate `Portfolio_Dashboard.xlsx` in the same folder with:
- **Executive Dashboard** sheet (main visual dashboard)
- **Data Source** sheet (detailed data tables)
